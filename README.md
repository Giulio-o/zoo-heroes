# ZOO HEROES

[Gioca subito dal browser](https://giulio-o.github.io/zoo-heroes/)

Demo educativa gratuita di carte e animali per bambini dai 6 anni, utilizzabile dal browser di smartphone, tablet e computer.

## Come giocare

1. Scegli il nome dell’esploratore e la fascia d’età.
2. Visita la Mappa e avvia una missione nella Savana.
3. Rispondi al quiz, scegli uno dei tre animali e usa la sua abilità.
4. Riscatta le ricompense, allena gli animali e sblocca nuovi habitat.

La demo comprende collezione di carte, specializzazioni, allenamenti, fusioni, pacchetti ricompensa e costruzioni dell’Accademia.

## Progressi e privacy

I progressi sono salvati nel browser del dispositivo tramite localStorage. Non c’è sincronizzazione tra dispositivi o browser. La demo non richiede account e non include pubblicità, acquisti, analytics o risorse esterne.

## Pubblicazione

GitHub Pages pubblica `index.html` dal ramo `main`, cartella `/` (root). Non sono necessari compilazione, dipendenze o installazioni.

Il file `index.html` riprende senza modifiche la demo ZOO HEROES già sviluppata.

## Verifica smartphone

La [pagina di collaudo](https://giulio-o.github.io/zoo-heroes/qa/mobile.html) apre il gioco con larghezze di 320, 360, 390 e 412 CSS pixel. Consente di controllare l’impaginazione e le interazioni nel browser; non simula hardware, sistema operativo o touch di un telefono reale.
